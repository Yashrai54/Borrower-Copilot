# Borrower Copilot

A local-only borrower decision-support tool for Indian borrowers.

## What it does

Borrower Copilot evaluates:
- Whether borrowing is advisable
- How much the borrower can safely afford
- Indicative lender-side capacity
- Fair interest-rate range
- Safe EMI ceiling
- Negotiation points for the lender

## Key Product Principle

The tool separates:

Borrower affordability ≠ Lender approval capacity

A lender may be willing to lend more than the borrower can safely repay.
